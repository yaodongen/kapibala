# 日期与时间写法 · 支持清单

在添加栏的标题里直接写日期和时间，旁边的**日期框和时间框会自动填好**：

| 你写的 | 自动填成 |
| --- | --- |
| `明天下午3点开会` | 2026-09-28 15:00 |
| `20260630 吃饭` | 2026-06-30（全天） |
| `next monday at 3pm review` | 2026-09-28 15:00 |

- **标题原文一个字都不改**，只有旁边那两个框被填上。
- 框里你已经手动改过的值，不会再被标题覆盖。
- 认不出来就不填 —— 宁可空着，也不替你猜一个日子。
- 只填了日期、没填时间 = **全天**；填了时间才是"定了点"。
- 年份**只认今年到今年 + 10 年**（2026 年就是 2026–2036），超出的一律不填。

> 下面所有例子的"今天"都按 **2026-09-27（周日）** 算。实际使用时以你当天的日期为基准，
> 所有相对说法（明天、下周三、in 3 days）都跟着当天走。

### 绝对日期

| 写法 | 例子 | 结果 |
| --- | --- | --- |
| M月D日 / M月D号 | `3月5日交报告` | 2027-03-05 全天（今年已过 → 明年） |
| | `9月1日交报告` | 2027-09-01 全天 |
| YYYY年M月D日 | `2026年8月28日开会` | 2026-08-28 全天 |
| D号 / D日 | `28号交报告` | 2026-09-28 全天（本月还没到） |
| | `5号交报告` | 2026-10-05 全天（本月已过 → 下月） |
| 下个月D号 / 下月D号 | `下个月5号交报告` | 2026-10-05 全天 |
| 本月D号 / 这个月D号 | `本月28号交报告` | 2026-09-28 全天 |
| YYYY-MM-DD | `2026-08-28 meeting` | 2026-08-28 全天 |
| YYYY/MM/DD | `2026/08/28 meeting` | 2026-08-28 全天 |
| YYYY.M.D | `2026.06.30 吃饭` | 2026-06-30 全天 |
| | `2026.6.30 吃饭` | 2026-06-30 全天 |
| YYYYMMDD（8 位连写） | `20260630 吃饭` | 2026-06-30 全天 |
| YYMMDD（6 位连写） | `260630 吃饭` | 2026-06-30 全天 |
| MMDD（4 位连写） | `0630 吃饭` | 2027-06-30 全天（今年已过 → 明年） |
| M/D（美式 月/日） | `8/28 meeting` | 2027-08-28 全天 |
| M/D/YYYY | `8/28/2026 meeting` | 2026-08-28 全天 |

`YYMMDD` 的年份：`00`–`79` 算 20xx（`260630` → 2026），`80`–`99` 算 19xx。
不过算出来的日子还要过下面那道年份窗口 —— `991231` 虽然能算出 1999，但落在窗口外，**不认**。

## 日期和时间一起写

日期和时间分开认、认到了就合起来。日期在前在后都行。

| 例子 | 结果 |
| --- | --- |
| `明天下午3点开会` | 2026-09-28 15:00 |
| `明晚7点吃饭` | 2026-09-28 19:00 |
| `2026-08-28T19:30 上线` | 2026-08-28 19:30 |
| `2026.06.30 19:30 吃饭` | 2026-06-30 19:30 |
| `tomorrow at 9:30am standup` | 2026-09-28 09:30 |
| `tomorrow morning standup` | 2026-09-28 09:00 |
| `next monday at 3pm review` | 2026-09-28 15:00 |
| `tonight at 8pm movie` | 2026-09-27 20:00 |

### 紧凑时刻

8 位 / 6 位 / 4 位连写的日期后面，可以再跟一个连写的时刻（`T1930`，或空格加 `1930`）：

| 例子 | 结果 |
| --- | --- |
| `20260630T1930 吃饭` | 2026-06-30 19:30 |
| `20260630 1930 吃饭` | 2026-06-30 19:30 |
| `260630 1930 吃饭` | 2026-06-30 19:30 |

**连写的时刻只跟在连写的日期后面。** 单独一个 `1930` 不会当成 19:30；用 `-`、`/`、`.`
分隔的日期后面也请写 `19:30`（`2026-08-28T19:30` 是认的）。

## 几条约定

1. **只填日期 = 全天**；填了时间才是定时任务。
2. **只认到时间、没认到日期**，按今天那个点算（`下午三点开会` → 今天 15:00）。
3. **年份只认「今年 ~ 今年 + 10 年」**。今年是 2026 年，所以只认 **2026-01-01 ~ 2036-12-31**。
   超出这一段的一律不认 —— 那些几乎都是编号、金额被误当成了日期，或者年份写错了
   （`991231` → 1999、`000630` → 2000、`20990630` → 2099）。相对说法也一样：
   `10年后` 认，`11年后` 就超出窗口、不认。
   *代价：窗口下沿是今年 1 月 1 日，所以 1 月初说 `前天`、`上周三` 如果落到了去年，
   也会被挡掉 —— 宁可那天不预填，也不认一个去年的日子。*
4. **没写年份、但今年这天已经过了 → 算明年**：`3月5日`、`5号`、`jan 5`、`8/28` 都是这个规矩。
   写全了年份就按写的年份（前提是落在上面那个窗口里）。
5. **光说星期几取最近的一次**（今天正好是这天就算今天）；`下周X` / `本周X` / `上周X`
   按周一为周首的那一周算；"周末"算最近的**周六**。
6. **只说到时段没说到点**，落一个约定整点：

   | 时段 | 默认 |
   | --- | --- |
   | 上午 / 早上 / 早晨 / 清晨 / morning | 09:00 |
   | 中午 / 正午 / noon | 12:00 |
   | 下午 / afternoon | 15:00 |
   | 傍晚 / 晚上 / 夜里 / night | 20:00 |
   | 凌晨 / midnight | 00:00 |

7. **中午按中文习惯还原**：中午 12 点 = 12:00，中午 1 点 = 13:00。
8. **4 位纯数字按"月日"读，不按钟点读**：`0630` 是 6 月 30 日、`1130` 是 11 月 30 日，
   都不是 11:30 / 06:30。
9. 标题原文不改；日期/时间框里被你手动改过的值不会再被覆盖。

## 不支持

| 写法 | 为什么 |
| --- | --- |
| `6月30` | 省了"日/号"（`6月30日`、`6月30号` 都认） |
| `6.30` / `6-30` | 没写年份的点/横线月日（会跟小数、区间撞：`3.5 小时`） |
| `30/6` | `/` 一律按美式 **月/日** 读（`30/6` 当 30 月不成立） |
| `630` | 三位数太容易是别的意思 |
| `二〇二六年六月三十日` / `六月三十日` | 中文数字只用在"点/分"上 |
| `2026` / `2026年` | 只有年份，不构成一个日子 |
| `1930` | 单独的 4 位纯数字不当时刻（见上面"连写的时刻"） |
| `2026.06.30T1930` | 连写时刻只跟在**连写**日期后面；点分隔请写 `2026.06.30 19:30` |
| `991231` / `000630` | 算出来是 1999 / 2000，在年份窗口之外 |
| `20990630` / `20370101` | 在 2036 年之后，超出年份窗口 |
| `11年后` / `20年后` | 超出年份窗口的相对说法也不认（`10年后` 认） |
| `前天`（1 月初，跨到去年） | 落在去年，超出年份窗口 |
